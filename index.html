Lab guide

Aim: Simulate CPU scheduling and calculate completion time (CT), turnaround time (TAT), and waiting time (WT).

  1. Enter process ID, arrival time, and burst time.
  2. Choose FCFS, SJF, RR, or MLFQ.
  3. Use Step or Play to observe allocation on the Gantt chart.
  4. Compare mean waiting and turnaround times.
while unfinished processes exist: add arrived processes to ready queue if ready queue empty: jump to next arrival choose process by scheduler policy run for burst time or time quantum if complete: CT = current time otherwise reinsert according to policy TAT = CT - arrival; WT = TAT - burst
// FCFS core in C int time = 0; for (int i = 0; i < n; i++) { if (time < p[i].arrival) time = p[i].arrival; time += p[i].burst; p[i].completion = time; p[i].turnaround = time - p[i].arrival; p[i].waiting = p[i].turnaround - p[i].burst; }

Input: process ID, arrival time, burst time, priority, algorithm, and time quantum when applicable.

Output: Gantt chart, execution log, completion order, average waiting time, and average turnaround time. The gold outline marks the current CPU slice.

What is turnaround time?

TAT = completion time − arrival time.

What is waiting time?

WT = turnaround time − burst time.

How does SJF break ties?

The earlier arrival, then earlier list position, is selected.

How does MLFQ work here?

New jobs begin in Q1. A job consuming its full Q1 quantum moves to Q2, which gets a larger quantum.
